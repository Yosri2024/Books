À propos de ce résumé

Le livre enseigne les bases de Linux à travers le prisme de la sécurité offensive, entièrement construit autour de Kali Linux. Chaque chapitre est pratique : les commandes sont enseignées avec leur pertinence pour la reconnaissance, l’exploitation, la furtivité et l’automatisation.

Partie 1

Compétences de base (Ch. 1–7)

1Démarrer avec les bases

Terminal et hiérarchie du système de fichiers de Kali, commandes de survie, recherche de fichiers et manipulation de base (créer, copier, renommer, supprimer).

  • pwd / whoami : s’orienter et confirmer son niveau de privilège.
  • man : la référence pour la syntaxe de chaque commande.
  • find : recherche flexible (nom, type, taille, date), essentielle pour localiser des fichiers intéressants.
  • grep : filtre la sortie texte, souvent enchaîné avec d’autres commandes.
$ pwd                                   # /root
$ whoami                                # root
$ man nmap
$ find / -name "*.conf" -type f 2>/dev/null
$ cat /etc/passwd | grep bash
cdlocatewhereiswhichtouchmkdircpmvrmrmdirpwdwhoamimanfindgrep

2Manipulation de texte

Afficher des parties de fichiers, numéroter les lignes, filtrer, rechercher/remplacer et paginer.

  • head / tail : début ou fin d’un gros fichier (ex. logs) sans tout ouvrir.
  • sed : recherche/remplacement non interactif, utile pour modifier rapidement des configurations.
  • less : défilement et recherche dans de gros fichiers sans les charger en mémoire.
$ tail -n 20 /var/log/auth.log
$ sed 's/PermitRootLogin no/PermitRootLogin yes/' /etc/ssh/sshd_config
$ less /var/log/syslog      # / pour chercher, q pour quitter
headtailnlsedmoreless

3Analyse et gestion des réseaux

Interfaces (ifconfig, iwconfig), changement d’IP, masque, broadcast et adresse MAC, inspection DNS et mappage manuel des noms d’hôte.

  • ifconfig / iwconfig : point de départ de toute reconnaissance réseau.
  • macchanger : usurpation d’adresse MAC pour éviter la détection ou un contrôle d’accès.
  • dig : interroge les serveurs DNS et révèle les enregistrements d’un domaine.
  • /etc/hosts : associe des noms d’hôte à des IP choisies (tests, redirection).
$ ifconfig eth0
$ iwconfig wlan0
$ ifconfig eth0 down && macchanger -r eth0 && ifconfig eth0 up
$ dig hackers-arise.com
$ echo "192.168.1.50 target.local" >> /etc/hosts
dhclient/etc/resolv.confifconfigiwconfigmacchangerdig

4Ajout et suppression de logiciels

Gestion des paquets Debian/Kali avec apt, ajout de dépôts via sources.list, installateurs graphiques et installation depuis les sources avec git.

$ apt search exploit

5Autorisations de fichiers et répertoires

Modèle utilisateur / groupe / autres, propriété, chmod (octal et symbolique), umask et permissions spéciales (SUID, SGID, sticky bit).

$ chmod 755 script.sh        # octal
$ chmod u+x script.sh        # symbolique
$ umask 022                  # masque par défaut
$ chown root:root /etc/myconfig
$ find / -perm -4000 -type f 2>/dev/null   # fichiers SUID
Élévation de privilègesSUID fait tourner un programme avec les droits de son propriétaire (souvent root), quel que soit l’utilisateur : cible classique d’escalade.
ls -lSUID/SGIDchmodchownchgrpumask

8Scripts Bash

Premier script (« Hello, Hackers-Arise! »), permissions d’exécution, variables, saisie utilisateur. La pièce maîtresse : un scanner de ports, amélioré en scanner MySQL (port 3306) sur une plage d’IP avec boucles et conditions.

echo "Hello, Hackers-Arise!"

$ chmod +x HelloHackersArise.sh && ./HelloHackersArise.sh

read -p "Enter target IP range prefix: " prefix
for ip in 192.168.1.{1..254}; do

done

11Le système de journalisation

Démon rsyslog et règles facilité.priorité, rotation avec logrotate, puis, présenté pour la sensibilisation et la défense, effacement de traces et désactivation de la journalisation.

$ cat /etc/rsyslog.conf      # auth,authpriv.*  /var/log/auth.log
$ cat /etc/logrotate.conf
$ sed -i '/192.168.1.77/d' /var/log/auth.log
$ systemctl stop rsyslog
Côté défenseCes techniques anti-forensiques montrent ce qu’il faut surveiller : lignes manquantes dans les logs et arrêt inattendu de rsyslog.

13Devenir sécurisé et anonyme

Comment Internet révèle l’identité (IP, métadonnées), puis couches d’anonymat : Tor (routage en oignon), proxys, VPN et e-mails chiffrés.

  • Tor : trafic relayé via plusieurs nœuds chiffrés.
  • Proxy : intermédiaire, mais anonymat généralement plus faible que Tor.
  • VPN : tunnel chiffré qui masque l’activité au réseau local (FAI).
  • GPG/PGP : protège le contenu des messages.
$ apt install tor && service tor start
$ torify curl https://check.torproject.org
$ export http_proxy="http://127.0.0.1:8080"
$ openvpn --config myvpn.ovpn
$ gpg --encrypt --recipient alice@example.com message.txt

15Noyau et modules chargeables

Qu’est-ce qu’un module, version du noyau, paramètres à chaud avec sysctl, gestion des modules : pertinent pour les pilotes comme pour les rootkits noyau.

$ uname -r                   # 5.4.0-kali3-amd64

$ modinfo usbcore
$ insmod mymodule.ko
$ modprobe -r mymodule
À retenirLa version du noyau sert à faire correspondre des exploits à une cible ; le chargement de modules est le mécanisme que détournent les rootkits.
